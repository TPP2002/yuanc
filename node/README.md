# 出口小主机基础程序

这份程序负责检查配置、记录安装过程、查看网络情况和撤回安装。
它目前还不能让电脑通过澳洲出口上网：代理、账户授权、管理服务、自动恢复和更新由后续任务接入。

## 首次使用

请让维护人员在 Debian 12 或 Ubuntu 24.04 的测试机上准备 Python 3.11 或更新版本，以及系统自带的 systemd、iproute2 和 nftables。不要先在正在提供服务的机器上尝试安装。

本阶段不提供自动安装脚本或安装包，也不自动安装系统工具。Python 程序仅使用标准库。
将 `node/exitnode` 放到目标 Python 的模块搜索路径中；本地查看帮助时，可以先进入仓库的 `node` 目录：

```text
python -m exitnode --help
```

Windows 只用于开发和模拟测试。真实系统操作只支持 Linux；在 Windows 上查看帮助和查看“更新尚未实现”的提示不需要访问系统。

把 `examples/config.example.toml` 交给维护人员填写，并保存为 `/etc/exitnode/config.toml`。具体填写方法见 [配置说明](../docs/node/配置说明.md)。
不要把密码、令牌、设备身份或密钥写进配置文件。凭据只放在 `/var/lib/exitnode/secrets/`，不要把这个目录打包给别人。

## 七项操作

以下操作在模块已可被 Python 找到之后执行。安装、撤回、卸载需要足够的系统权限；服务启动时同样必须能找到该模块，不能只依赖当前终端目录。

| 操作 | 命令 | 会发生什么 |
| --- | --- | --- |
| 安装 | `python -m exitnode init` | 建立基础目录和服务定义，登记管理服务开机启用，写入本项目网络规则 |
| 检查 | `python -m exitnode check` | 按顺序显示网卡、上游、入口、代理、实际出口的检查结果 |
| 状态 | `python -m exitnode status` | 显示正常、重连中、需重新授权或需人工处理 |
| 导出诊断 | `python -m exitnode diagnose --output /tmp/exitnode-diagnose.zip` | 导出配置、检查结果、版本和最近日志，自动打码凭据字段 |
| 更新 | `python -m exitnode upgrade` | 明确提示尚未实现并返回失败，由后续更新任务接入 |
| 撤回 | `python -m exitnode rollback` | 按安装记录倒序撤回；一项失败仍继续处理其他项 |
| 卸载 | `python -m exitnode uninstall` | 撤回组件并清除安装清单，保留凭据和其他仍存在的数据 |

使用其他配置位置时，加 `--config /绝对路径/config.toml`。检查和状态命令可加 `--json`，供其他程序读取。

## 怎样理解结果

“安装成功”仅表示基础组件登记成功，不表示网络出口可用。管理和代理服务现在是明确报错的占位入口；管理服务只登记启用，不在安装时启动。定时检查单元已提供，但不会自动启用。

网卡与上游是目前真正执行的两层检查。入口、代理和真实出口始终显示“未接入”，不冒充通过。“正常”只表示已经接入的检查通过，说明文字仍会提醒出口尚未验证。连接方式为未知，最后一次真实出口成功时间为空。

多个上游目标中有一个可连接就不判定上游中断；不会因为某一个网站无法访问就重启主机。本阶段不会自动重启服务或主机。

## 安装中断和撤回

默认记录位于 `/var/lib/exitnode/manifest.json`。请保留它：重复安装会跳过完成的步骤，中断后会继续未完成步骤。不要手工删除记录后再次安装，否则程序无法确认已有服务和规则是否属于本次安装。

撤回失败时会列出失败项，排除权限或系统工具问题后可再次撤回。`rollback --to-step 步骤名` 会保留指定步骤及之前的步骤。原有同名服务或网络规则不在清单里时，安装会停止，让维护人员核对，不会擅自覆盖。

普通卸载保留凭据。只有确定永久弃用节点时，才使用 `uninstall --purge` 删除整个凭据目录；该操作无法恢复。其他未清空的目录会保留，不递归删除用户文件。

## 开发检查

测试通过模拟系统执行器运行，不调用真实的服务管理、防火墙或网络工具。黄金文件固定了服务定义和网络规则的预期文本。
本工位的测试和规范检查必须通过派单器自测入口运行，不要自行安装依赖或直接启动测试。自动检查流程会检查 Python 3.11、3.12；客户端方案文件存在时才执行客户端工具准备和测试，草稿合并请求也会检查。

真实 Linux 安装、权限、服务加载以及澳洲出口上网仍需后续环境验收；模拟测试不能代替这些结论。
