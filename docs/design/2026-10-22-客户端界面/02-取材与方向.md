## 2. 这个题目独有的东西(取材清单)

1. **看板的「灯条」语言**——负责人唯一点名满意的东西:边框流不流 = 在不在等,底色 = 好坏,记号 = 在干嘛。
2. 出口是一条固定的澳洲家庭宽带,IP 一直是澳洲;整个产品的承诺就一句「使用中 IP 一直是澳洲宽带」。
3. 断网保护是兜底:连着的时候,隧道断了就整机断网,不漏流量。
4. 一节点一使用者,没有多账号、多节点切换,界面不需要「服务器列表」。
5. 两种接入方式并存:自用导入配对文件;分发版兑换邀请码。
6. 后台服务 + 托盘界面,窗口可关,隧道不受影响。
7. 四项状态天然成行:出口 IP / 断网保护 / 环境自检 / 环境一致性。
8. 节奏有数:巡检每 60 秒,出口复查每 5 分钟。
9. 澳洲:不画袋鼠、不画地图,澳洲只出现在文字里。
10. Windows 系统主题浅 / 深,用户自己会切。
11. 管理员远程排查靠一个导出文件(防火墙审计 + 环境自检),不含出口 IP。
12. 局域网设备(打印机、路由器页)连接中照常可用,这是 10-22 刚拍的板,值得写在界面上。

**一句话**:在这个界面上,「灯条语言」变成了**连接状态瓦片**——它是整个窗口唯一会动的东西;连上那一刻整块填绿、勾画一笔,之后就安静。四行状态各带一枚小瓦片,和看板任务卡上的状态记号是同一套语法。

## 3. 方向(只一个:借鉴看板)

负责人已经指定画风,不出多方向比稿。六条差异轴上和旧界面的差别:

| 轴 | 旧界面 | 新界面 |
|---|---|---|
| 组织方式 | 一列到底、全部居中 | 左侧五项导航 + 右侧一页一事;连接页英雄卡在最上面 |
| 密度 | 松散但没有层级 | 紧凑:行高 44,间距 8/12/16/24,正文 16 |
| 色彩策略 | 浅蓝灰底 + 四个裸色值 | 看板同款暖灰底 / 白卡 / 四档语义色;深色一套跟随系统 |
| 表面处理 | 无 | 1px 细线卡片、极淡阴影(深色关掉)、小圆角 6/8 |
| 字体角色 | 系统默认一字号到底 | 微软雅黑 UI 正文,等宽只给 IP / 版本 / 路径;粗体只给标题与主按钮 |
| 动效性格 | 没有 | 安静:只在等的时候流光;连上勾画一笔;按下 120ms;切页 180ms 淡入上移;系统关动画则全停 |

**换题自查**:把这套搬去「打印机管理器」,颜色、布局、卡片都能原样用——它们是看板的,不是这个产品的;瓦片的状态表(八种连接状态各一枚、四行各一枚)搬不走,它就是这个产品的状态机。所以记忆点落在瓦片上是对的。

## 4. 记忆点与配饰

- **一处记忆点**:英雄卡的 56px 状态瓦片,以及「连上那一刻勾画一笔」。
- **处处手感**:按钮按下 120ms 缩 3%、底色变深;导航项悬停换底;开关滑块 180ms;出口 IP 数字换了做一次 300ms 淡入上移。
- **摘掉的一件配饰**:侧栏顶部的品牌行(图标 + 名字)——标题栏已经写着名字,重复了,摘。

## 5. AI 味自查(只查新加部分)

硬禁项:emoji 当图标 0(旧界面的「⚠」已去掉);复述标题的小标签 0;一切居中 0;紫靛渐变 0;假数据 0(样张的演示值都标注了「演示」)。

默认禁项计数:
1. 卡片 + 淡阴影 —— 1 个,理由:看板同款,阴影两层各 4%~5%,深色主题关掉,不是「一个大圆角 + 同款阴影管全站」(圆角只有 6/8,英雄瓦片 14 是记忆点的一部分)。
2. 线性图标做导航 —— 不计:通用做法,配常显文字,线宽 1.75 与看板一致。

计数 1,过线。

## 6. 文案规则(给施工方)

- 中文页不用英文大写等宽小标签;英文只出现在 IP、版本、路径、`en-AU` 这类原样引用里。
- 按钮写结果:连接 / 断开 / 安装后台服务 / 修复后台服务 / 重新连接后台服务 / 兑换邀请码 / 导入配对文件 / 清除本机配对文件 / 添加程序… / 移除 / 检查更新 / 导出诊断…
- 禁用处写原因,不留一个灰按钮让人猜。
- 失败文案三段:出了什么事 → 现在的后果 → 请做什么;不责备。
- 汇报口径只讲隧道、分应用、断网保护、防泄漏、环境一致、承诺边界,不出现「反追踪 / 隐匿 / 伪装」之类的词。
