# 客户端界面改版 · ① 产品事实卡与旧界面走查

> 卡:WINCLIENT-UI-DASHBOARD-STYLE-1022。负责人 2026-10-22 原话:「Windows 要的是可视化的界面 .exe 程序,我感觉 UI 你可以借鉴看板,看板的 UI 设计我还是很满意的」「记得要有动画动效啥的」。
> 档位:B 局部改版(负责人已指定借鉴看板的成型画风,跳过多方向比稿;只对新加的部分查 AI 味)。模式:操作型。

## 1. 产品事实卡

| 项 | 事实 |
|---|---|
| 谁用 | 客户(中国境内的 Windows 用户,一节点一使用者)日常用;负责人验收;都不读代码 |
| 在哪用 | Windows 10 / 11 桌面;办公或家用显示器,100%~150% 系统缩放;室内光线 |
| 主题 | 跟随系统浅色 / 深色(负责人自己的电脑用深色,看板也是深色模式在看) |
| 真实浏览器 | 不适用,WPF 原生窗口;没有手机端 |
| 主任务与频率 | 开机点一次「连接」,然后窗口缩到托盘;偶尔打开看一眼四项状态;少数时候改代理范围、导入配对文件或兑换邀请码、检查更新、导出诊断给管理员 |
| 用户熟练度与情绪 | 普通用户;出问题时焦虑,最想知道「现在是什么情况、我要做什么」 |
| 必须保留 | ViewModel 的全部命令与字段(连接 / 兑换 / 导入配对 / 清除配对 / 检查更新 / 添加与移除程序 / 导出诊断 / 环境一致性开关 / 代理范围两选);关窗 = 缩到托盘;托盘菜单四项与双击打开;单实例唤起;`AutomationProperties.LiveSetting` 挂在变化的消息文本上;选文件对话框;`Program.cs` 的角色参数与安装 / 修复路径;**红字常驻**(隧道断了不静默回落的界面体现) |
| 技术约束 | .NET 9 WPF + Windows Forms(托盘);工位无外网、不新增 NuGet;`WinClient.Core` 一字不动;现有测试工程是 `net9.0`,引用不了 WPF,界面测试要新开 `net9.0-windows` 工程;CI 在自托管 Windows runner 上跑 `dotnet test winclient`;Windows 子进程一律隐藏窗口 |
| 现有界面测试 | 没有,HTML/XAML 没有被任何测试钉住 |
| 数据来源 | `ControlSnapshot`:State / Status / Message / ProtectionActive / Mode / ExitStatus / ExitIp / GuardStatus / EnvironmentEnabled / EnvironmentStatus / SelfCheckStatus / RoutingMode / RoutingApps / ServiceVersion / Update;自检明细经 `read_selfcheck` 读 JSON(`checked_at` / `summary` / `items[{id,name,result,detail}]`) |

## 2. 旧界面走查(`MainWindow.xaml`,480×900 单列)

| # | 发现 | 严重度 | 去向 |
|---|---|---|---|
| 1 | 所有内容堆成一列、全部居中,主次不分;68px 高的主按钮夹在中间,状态文字在它下面 | 高 | 改版:侧栏分页,连接页英雄卡 + 四行状态 |
| 2 | 用「⚠」字符当图标(硬禁项);状态只靠文字,没有颜色与记号 | 高 | 改版:状态瓦片(底色 + 记号),文字照旧说清 |
| 3 | 多处 11px 文字(代理范围提示、RoutingLine);底线辅助文字 ≥13px,12px 只给极少量标注 | 高 | 改版:正文 16 / 辅助 14 / 标注 12 |
| 4 | 裸色值写在 XAML 里(`#F5F7FA` `#536174` `#8A2E2E` `#6B4B20`);没有深色主题 | 中 | 改版:全部走资源字典 token,浅深两套跟随系统 |
| 5 | 禁用的控件不说原因:连接中「清除配对文件」「代理范围」整块灰掉,用户不知道为什么 | 中 | 改版:禁用处旁边一句原因(「连接中不能改,请先断开」) |
| 6 | 按钮文案不说结果:「兑换」「修复」「重试」;主按钮上挂着长句「安装后台服务(需管理员确认一次)」 | 中 | 改版:「兑换邀请码」「修复后台服务」「重新连接后台服务」「安装后台服务」,解释放副标题 |
| 7 | 没有任何状态切换反馈与等待安慰;IsBusy 只是把按钮灰掉 | 中 | 改版:瓦片流光只在等的时候动,按下有 120ms 反馈,忙碌态按钮文字变「正在…」 |
| 8 | 状态文字没有预留位:Message 变长时整列下移,主按钮位置跟着跳 | 中 | 改版:主消息槽固定两行高;主按钮在英雄卡右侧固定列 |
| 9 | 托盘图标是系统默认的应用图标,看不出连没连上 | 中 | 改版:五枚状态托盘图标(`Assets/tray-*.ico`) |
| 10 | 常驻警示「全部流量模式下,部分程序自带防火墙放行规则,断线时可能仍可直连」与现状不符(断网保护已做 DisableForeignAllowRules 与三档默认阻断),属过时文案 | 中 | 改版:删掉;代理范围页用一句现状描述(「隧道断了就整机断网,不漏流量;局域网设备照常可用」) |
| 11 | 键盘焦点用 WPF 默认虚线框,对比弱 | 低 | 改版:统一 FocusVisualStyle(2px 焦点色描边) |
| 12 | 「导出诊断」是 Click 事件不是命令,忙碌时靠 `!model.IsBusy` 判断 | 低 | 保留,不动逻辑 |
| 13 | 更新消息、后台版本、模式三条散在中间 | 低 | 改版:版本与更新进「更新与诊断」页;模式做成页头徽章;侧栏底部常显后台服务状态 |

## 3. AI 做不到、要真机的项(交负责人或客户)

- 150% 缩放下窗口字是否清楚、瓦片记号是否糊;
- 深色模式下 Windows 标题栏是否跟着变深(DwmSetWindowAttribute 在 Win10 1903 以下无效,只能忽略);
- 系统「动画效果」关掉后,瓦片是否完全静止;
- 托盘图标在浅色 / 深色任务栏各看一眼(16px);
- 连接 → 断开 → 重连整条流程里主按钮位置是否一次都没跳。
