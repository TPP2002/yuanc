# 节点管理网页 · 事实卡(2026-11-27)

卡 NODE-WEB-CONSOLE-1127。档位 B:沿用 `docs/design/2026-10-22-客户端界面/DESIGN.md` 的配色、字体、尺度和状态小方块,不另出方向。样张 `样张.html` 里标「搬进 console.css」的那段样式就是页面样式的正本。

| 项 | 内容 |
|---|---|
| 谁用 | 客户本人(管理员),不懂技术;人在国内时经客户端隧道打开,在澳洲现场时经局域网打开;负责人调试时也用 |
| 设备 | Windows 电脑上的 Chrome、Edge 为主;手机浏览器偶尔用 |
| 多久用一次 | 低频:给新人发码、到期前续期、出问题时看一眼状态;每次几分钟,看完就关 |
| 这一页管什么 | 节点好不好(四档状态加各层检查)、发邀请码、账号延期与停用、吊销设备。详细诊断仍归命令行 `exitnode diagnose` |
| 必须保留 | 与客户端同一套颜色、字体和状态小方块,一眼认得是同一个产品 |
| 技术约束 | 页面只有三件同源文件,不引外部字体和图片;内容安全策略只放行同源文件,不写内联脚本、style 属性和 onclick;明文 HTTP 下浏览器不给剪贴板接口,复制要有退路;备注、设备名是用户写的,一律当文本显示,不当 HTML |
| 不做 | 换主题开关、多管理员、邀请码作废(鉴权服务没有这个接口)、在网页里加自用设备 |

## 三个页签

- **状态**:总状态(小方块 + 状态名 + 一句原因 + 公网地址 + 检查时间),下面各层检查一行一层;有本机自用设备时列在最后。记录过期时总状态下方出一条琥珀色提示。
- **邀请码**:一行表单(天数快捷键 7/30/90/365 加输入框、可用人数、备注、生成),生成后新码大字显示带复制;下面是已生成的码,新的在前。
- **账号**:一张账号一块,按「使用中 → 已过期 → 已停用」排,同组内先到期的在前;块头是备注(没有备注写邀请码)、到期日、剩几天、延期和停用按钮;块里一行一台设备,带吊销按钮。吊销要在原地再点一次「确认吊销」。

节点没开邀请码模式时只有「状态」一个页签。
