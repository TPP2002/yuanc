# 节点名单同步

分发版使用邀请码时启用名单同步。自用版不需要启用。

## 开启

在节点配置中添加或修改以下三项：

```toml
[authsync]
enabled = true
url = "http://127.0.0.1:8000"
spki_sha256 = ""
```

`url` 填鉴权服务器地址，不带路径和末尾斜杠。同机部署可用 `http://127.0.0.1` 和实际端口，此时指纹留空。使用 HTTPS 时，填服务器的 HTTPS 地址，并在 `spki_sha256` 填与客户端配置相同的证书公钥指纹。

把鉴权服务器的节点密钥写入 `/var/lib/exitnode/secrets/authserver-node-key`，文件权限设为 `0600`。密钥不写进配置文件。然后重跑一次 `exitnode init`。

已安装的节点升级后，也要在配置里加 `[authsync]` 并重跑一次 `init`，才会安装和启用定时器。

## 运行和查看

定时器每分钟从鉴权服务器获取名单并发送心跳。新兑码的设备最长约一分钟后才能连接。名单变化时，隧道服务重载一次，在线设备会断开并自动重连。

鉴权服务器连不上时，节点保持现有名单，吊销要等连接恢复后才生效。自用设备不受名单影响。

执行 `exitnode authsync status` 查看最近同步记录；`exitnode check` 中的「名单同步」一行显示定时器和最近同步情况。

## 真机待验证

- Debian 12 的 curl 使用 `--insecure` 时，`--pinnedpubkey` 仍能拒绝公钥指纹不符的服务器。
- 定时器每 60 秒触发一次。
- 隧道服务重载后，在线设备自动重连。
- 同机使用 `http://127.0.0.1` 部署鉴权服务器。
