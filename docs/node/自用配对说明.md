# 把小主机与自己的电脑配对

小主机已经安装好后，按下面三步操作，不需要另外准备服务器。

1. 在澳大利亚的小主机终端输入一条命令：

   ```sh
   sudo exitnode device add --name 老板的电脑
   ```

2. 终端会显示配对文件的位置，例如 `/var/lib/exitnode/export/老板的电脑.ycpair`。记下这个位置。它还会显示连接链接；装有二维码工具时也会显示二维码。如果提示没有二维码工具，文件和链接仍然可以使用；需要二维码时可运行 `sudo apt install qrencode` 后重新导出。

3. 把显示的配对文件拷到 U 盘带去电脑，在支持此功能的电脑客户端中选择“导入配对文件”，选中该文件，再连接。配对文件、链接和二维码都能用于连接自己的小主机，请妥善保管，不要公开分享。

首次安装成功时，小主机会自动生成名为“第一台电脑”的配对文件，并显示“请把这个文件拷到 U 盘带去电脑”。已经拿到这份文件时，直接从第 3 步开始；再次安装不会重复添加设备。

如果终端提示取不到公网地址，请确认小主机当前的公网 IPv4 数字地址，再手填。例如（下面的地址仅为示例，需要替换）：

```sh
sudo exitnode device add --name 老板的电脑 --host 203.0.113.10
```

给安卓设备准备配对资料时，在添加命令后加 `--platform android`。

## 旧版配对文件要重新导出

新版配对文件会带上备用线路需要的证书与校验名称。旧版文件仍可导入，但电脑会提示
“配对文件是旧版,备用线路可能不可用,建议在小主机上重新导出”。在小主机上运行
`sudo exitnode device export --name 老板的电脑`，把新文件拷到电脑重新导入即可。
使用安装时自动生成的设备时，把名字改成“第一台电脑”。重新导出不会更换设备凭据。

如果维护人员修改了备用通道的 `hy2_server_name`，须先重新生成对应名称的证书，再重新导出。
看到“备用通道证书已重新生成,旧配对文件需重新导出”时，也要把更新后的文件重新导入电脑。
单独的连接链接只包含主通道；要携带备用线路证书，请使用配对文件。

**备用通道启用混淆后要重新导出。** 维护人员在已装好的小主机上再次运行 `exitnode init` 启用备用通道混淆后
（终端会提示“备用通道已启用混淆,旧配对文件的备用线路将不可用,请重新导出”），之前导出的所有配对文件
备用线路都连不上了，主通道不受影响。请对每台设备运行 `sudo exitnode device export --name <设备名>`，
把新的 `ycpair/3` 文件拷到电脑重新导入。旧文件导入时电脑会提示
“配对文件是旧版,没有备用线路混淆参数;节点已启用混淆时备用线路不可用,建议在小主机上重新导出”。
新文件里的混淆密码与设备凭据一样要妥善保管。

真机待验证（尚未执行）：启用混淆后用新文件导入的电脑主备两条线路都能连通；抓包确认备用线路的 UDP 载荷
看不出 QUIC 明文特征；用旧 `ycpair/2` 文件的电脑主通道照常、备用线路失败且界面有上述提示。

## 公网地址变了

在小主机上重新导出同一台设备的文件：

```sh
sudo exitnode device export --name 老板的电脑
```

也可以在末尾加 `--host 当前公网IPv4地址` 手填。把新文件拷到电脑重新导入即可；重新导出不会更换设备的连接凭据。使用安装时自动生成的设备，请把名字改成“第一台电脑”。

## 查看和停用设备

```sh
sudo exitnode device list
sudo exitnode device revoke --name 老板的电脑
```

列表只显示名字、平台、登记时间和是否停用，不显示连接凭据。停用成功后，小主机立即更新连接许可；旧文件不能继续授权连接，该名字也不能重新导出或添加。需要重新授权时使用新的设备名字。

若提示配置校验失败，原登记表和正在使用的配置保持不变，请保留提示交给维护人员处理。若提示重载未成功，本次操作没有成功完成，请联系维护人员。
