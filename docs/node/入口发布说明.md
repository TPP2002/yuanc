# 入口端口映射

节点每十分钟向家庭路由器申请端口映射，把主通道 TCP 端口和备用通道 UDP 端口转发到小主机。外部端口与内部端口相同。每次申请一小时租期，在到期前续期；路由器只接受永久映射时，会改为申请永久映射。

## 安装与查看

在节点上安装工具：

```sh
apt install miniupnpc
```

安装或升级后运行 `exitnode init`，装上并启用定时器。已装好的节点升级后也要重新运行一次。

用 `exitnode publisher status` 查看最近记录；`exitnode status` 的「入口端口」一行显示摘要，`exitnode check` 的「入口端口映射」一行显示检查结果。申请失败时，检查结果显示「需手动转发」，手动转发后节点仍可使用。

## 失败时怎么办

- 未安装 miniupnpc：安装上面的工具，等待下一轮或运行 `exitnode publisher tick`。
- 没找到支持 UPnP 的路由器：检查路由器是否支持并开启 UPnP，也可以手动转发两个端口。
- 路由器拒绝了映射：检查端口是否已被其他设备占用，或路由器是否限制映射；也可以手动转发。
- 路由器外网口不是公网地址：上面可能还有一层路由器，或运营商使用共享地址。联系运营商换成公网地址；本程序的中继方式（`relay`）尚未实现，不能靠它解决。
- 执行失败：检查工具与系统环境，必要时手动转发两个端口。

换路由器后不用重新设置，最长十分钟后自动重新申请。卸载时程序会先申请删除映射；如果路由器只接受永久映射且删除失败，请到路由器页面手动删除。

这里只支持 UPnP，不支持 NAT-PMP。`relay` 方式是预留项，不申请映射。

## 真机待验证

2026-11-27 在负责人家里装机时用的是 `relay` 模式，家里的路由器不开 UPnP，下面五项都没测，要到澳洲现场测。

- 澳洲现场路由器是否开启 UPnP。
- 映射成功后外网能否连接。
- 租期到期前续期是否不断线。
- 换路由器后能否自动恢复。
- 小主机上其他防火墙是否拦截路由器的发现应答。
