# 出口小主机配置说明（初稿）

配置文件是给程序的一张设置单，不是存放密码的地方。首次填写请由维护人员协助，日常使用不需要修改。

## 文件放在哪里

- 普通设置：`/etc/exitnode/config.toml`。
- 凭据：`/var/lib/exitnode/secrets/`，目录只允许管理员访问，凭据文件应设为仅拥有者可读写。
- 安装记录：默认 `/var/lib/exitnode/manifest.json`。不要手工改动或删除。
- 日志：调用日志配置接口时可指定目录；诊断命令读取数据目录下 `logs/exitnode.log` 的最后一百行。

从仓库的 `node/examples/config.example.toml` 复制一份开始填写。示例不含任何可用凭据。带“请填写”的文字必须由维护人员替换成实际设置。

## 每一项怎么填

| 分组与字段 | 含义 | 默认或要求 |
| --- | --- | --- |
| `node.name` | 自己认识的节点名称 | 必填文字，不填密码或设备凭据 |
| `node.data_dir` | 安装记录和运行资料目录 | 当前固定为 `/var/lib/exitnode`，改了拒绝启动（救援程序按固定布局工作） |
| `node.secrets_dir` | 凭据目录 | 默认并限定为 `/var/lib/exitnode/secrets` |
| `node.log_level` | 日志详细程度 | 默认 `INFO`；支持 `DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` |
| `node.time_zone` | 节点所在城市的时区，随配对文件下发；客户端连接后切换电脑时区 | 可省略，默认空串；接受 IANA 名（如 `Australia/Sydney`）或 Windows 时区 ID。非空须全匹配 `[A-Za-z0-9 ._+/()-]{1,64}`；留空不写入配对文件，客户端用本机配置，无法识别也回落本机配置 |
| `node.country` | 节点所在国家，用作客户端出口国家自检的期望值 | 可省略，默认空串；非空须为两位大写国家码（如 `AU`，全匹配 `[A-Z]{2}`）。留空不写入配对文件，客户端用本机配置，再缺省时为 `AU` |
| `network.iface` | 使用哪块网卡检查 | 默认 `auto`，根据默认路由选择；也可填实际网卡名称 |
| `network.probe_targets` | 检查上游时尝试的地址 | 默认两个公共地址；必须为非空文字列表，可填主机名或地址 |
| `proxy.reality_port` | 主通道端口 | 默认 `443` |
| `proxy.hy2_port` | 备用通道端口 | 必填整数，示例为 `24443`；实际代理尚未接入 |
| `proxy.sni` | 主通道的伪装目标名称 | 必填，无默认；与 `proxy.handshake_server` 必须相同；推荐澳洲本地大站，由维护人员实测支持 TLS 1.3 与 HTTP/2 后填入，示例为 `www.abc.net.au` |
| `proxy.handshake_server` | 主通道握手时实际连接的伪装目标 | 必填，无默认；与 `proxy.sni` 必须相同，不相同拒绝启动（两者不一致是 Reality 配错的典型特征） |
| `proxy.maintenance_device_ids` | 维护设备的设备编号列表 | 默认空列表 `[]`；填写未吊销设备的 `device_id`。登记设备连上隧道后，可用 SSH 连接节点与局域网内其他机器的 22 端口；其他设备访问私网一律被拦 |
| `admin.bind` | 管理服务监听地址 | 必填地址，示例为 `127.0.0.1`，仅本机访问；必须是回环地址(`127.0.0.1` 或 `::1` 等),否则 `init` 拒绝安装(托管服务的 `IPAddressAllow=localhost` 只放本机连接) |
| `admin.port` | 管理服务端口 | 必填整数，示例为 `8443`；不小于 1024,否则 `init` 拒绝安装(托管服务以动态账户运行、没有绑定低端口的能力) |
| `publisher.mode` | 入口发布方式 | 必填 `upnp` 或 `relay`；`upnp` 每十分钟申请端口映射，见 [入口发布说明](入口发布说明.md)；`relay` 为预留项，不申请映射 |
| `publisher.ddns_provider` | 动态域名服务商 | 必填文字，当前不使用；不填服务商密码或令牌 |
| `publisher.domain` | 计划使用的域名 | 必填文字，当前不使用 |
| `updater.channel` | 更新通道 | 必填文字，示例为 `stable`；本阶段不执行更新 |
| `updater.check_interval` | 计划的更新检查间隔 | 必填正整数，单位为秒，示例为 `3600` |
| `updater.releases_dir` | 版本目录 | 当前固定为 `/opt/exitnode`，改了拒绝启动（救援程序按固定布局工作） |
| `updater.health_stable_sec` | 升级健康检查首次通过后再观察的稳定窗秒数 | 可省略，默认 `30`；须为非负整数，`0` 表示关闭稳定窗。详见 [更新与回退说明](更新与回退说明.md) |
| `authsync.enabled` | 是否同步鉴权服务器的名单 | 默认 `false`；分发版使用时设为 `true` |
| `authsync.url` | 鉴权服务器地址 | 默认空；启用时填写 HTTPS 地址，或同机的 `http://127.0.0.1` 地址 |
| `authsync.spki_sha256` | 鉴权服务器证书公钥指纹 | 默认空；HTTPS 必填与客户端相同的指纹，同机 HTTP 留空。详见 [名单同步说明](名单同步说明.md) |
| `console.enabled` | 是否装上节点管理网页 | 缺段时为 `false`；示例配置为 `true`。详见 [管理网页说明](管理网页说明.md) |
| `console.port` | 管理网页的局域网端口 | 默认 `8444`；须在 1024 到 65535 之间；开启管理网页时不能与 `admin.port`、`proxy.reality_port`、`proxy.hy2_port` 相同 |
| `console.lan` | 管理网页是否在局域网监听 | 默认 `true`；为 `false` 时只监听本机，只能从隧道或小主机本机打开 |

六个分组都要保留。端口必须为 1 到 65535 的整数，不要给数字加引号。文字须加双引号；不要改字段名称或添加程序尚不认识的字段。缺字段、类型错误和未知字段都会报中文错误并指出配置文件和字段位置。

不要把管理服务改成无保护的公网入口；管理服务和认证尚未接入，修改监听设置不等于获得安全的远程管理能力。本程序只维护自己的网络规则表，不关闭防火墙，也不会改变其他服务的规则。

## 填完之后

让维护人员先执行检查。网卡、默认路由和至少一个上游地址可用时，这两项会显示通过。无法确认是否通过自动地址分配取得地址时，程序会保留“未知”，不会猜测。

其余三层显示“未接入”是本阶段的明确边界，不能据此宣布出口已经可用。安装完成后还需接入代理、授权和管理程序，再进行实际网络验证。

## 出问题时怎样提供资料

使用诊断导出功能，不要把整个数据目录发给别人。诊断包不会读取凭据目录，会对日志中令牌、设备身份和密钥字段打码，但仍可能包含节点名称、网卡、地址和域名；分享前请检查这些信息是否适合提供。

安装中断时先保留原配置和安装记录，再续跑或撤回。需要更改已安装的服务定义时，请先由维护人员确认撤回和重装方式；重复安装会跳过已完成步骤，不会悄悄覆盖已确认设置。
