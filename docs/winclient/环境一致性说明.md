# Windows 客户端环境一致性

## 目的与承诺边界

连接到澳洲出口时，让系统时区与浏览器首选语言也与澳洲节点一致，减少网站从时区、语言、浏览器实时通信与定位接口取得不一致信息的机会。总开关默认开启，后台服务以 SYSTEM 身份执行；界面只发送指令和显示结果。

本包只承诺 IP、DNS、系统时区、浏览器首选语言四项的一致性目标，其中 IP 与 DNS 沿用既有隧道和断网保护，时区和语言按本说明设置。**不承诺任何检测都查不出**，也不把自动测试通过当作这四项的真机验收通过。环境设置失败仅告警：不改变连接状态、不停止隧道、不撤销断网保护、不自动断开；出口核验与断网保护仍按各自规则运行。

能做到：连接后设置目标时区、关闭自动时区，给 Chrome 与 Edge 设置语言、限制 WebRTC 只报告公网接口并拒绝网站定位；主动断开后按保存的原值恢复。连接期间任务栏时钟显示为澳洲时间，网站请求定位会被拒绝。

做不到与使用影响：

- **不改 Windows 显示语言**，也不更改操作系统的其他区域设置。
- 不改显卡、字体、画布等深层浏览器指纹；Firefox 等其他浏览器不覆盖。
- 策略是机器级的，对本机所有账户与所有浏览器配置档生效，并非仅当前用户或当前窗口。
- Edge 的 WebRTC 策略需重启浏览器才生效；应在连接后重启浏览器再进行相应验证。
- 不保证第三方软件、组织组策略或用户在连接期间再次修改设置后仍然一致；本单不增加环境巡检或自检报告导出。

## 时区切换

默认 Windows 时区 ID 是 `AUS Eastern Standard Time`。管理员按节点所在城市调整；此 ID 包括系统定义的夏令时规则，不是固定的时差。使用 `tzutil /g` 读原时区，`tzutil /s` 切换到目标时区，随后再读回核对。

自动时区来自 `HKLM:\SYSTEM\CurrentControlSet\Services\tzautoupdate` 的 `Start`：3 为按需启动（自动时区开启），4 为禁用。套用时先将 Start 设为 4，再尽力停止 `tzautoupdate`，随后切时区。恢复时先恢复原时区，再恢复原 Start；原值为 3 时尽力启动该服务。原 Start 读取不到时记录 null，不臆造原值。

读回的时区不等于目标时，状态文件写入 `verify_failed="time_zone"`，脚本退出码为 4，专用异常提示「时区切换未生效,可能被组策略锁定;连接与断网保护不受影响。」；其他命令失败同样保留原值记录。服务不把脚本标准输出或异常中的系统信息写进日志。一次执行最多 120 秒，复用既有隐藏窗口的 PowerShell 执行器，不新增进程类型。

## 浏览器六项策略

下面“六项”按浏览器策略计数：Chrome 的语言是一整个 `ForcedLanguages` 子键，另外五项是根键上的单值。不另外创建同名根值，不写 `ApplicationLocaleValue`，也不修改其他策略。

| 浏览器 | 注册表路径 | 值名 | 类型 | 写入值 | 原值记录 | 恢复方式 |
|---|---|---|---|---|---|---|
| Chrome | `HKLM:\SOFTWARE\Policies\Google\Chrome\ForcedLanguages` | `1`、`2`… | REG_SZ | 按序号 `en-AU`、`en`，或配置数组 | 子键是否存在及全部名称→值字典 | 原存在则清空当前值、逐个写回；原不存在则仅删除此子键 |
| Chrome | `HKLM:\SOFTWARE\Policies\Google\Chrome` | `WebRtcIPHandling` | REG_SZ | `default_public_interface_only` | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Chrome | 同上 | `DefaultGeolocationSetting` | REG_DWORD | `2`（拒绝定位） | 是否存在、原类型、原值 | 同上 |
| Edge | `HKLM:\SOFTWARE\Policies\Microsoft\Edge` | `DefinePreferredLanguages` | REG_SZ | `en-AU,en`，或配置数组以逗号连接 | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Edge | 同上 | `WebRtcLocalhostIpHandling` | REG_SZ | `default_public_interface_only` | 是否存在、原类型、原值 | 同上；需重启浏览器生效 |
| Edge | 同上 | `DefaultGeolocationSetting` | REG_DWORD | `2`（拒绝定位） | 是否存在、原类型、原值 | 同上 |

套用语言前先保存 `ForcedLanguages` 的所有值，再逐个移除当前值并按 1 起的序号写入目标语言。单值恢复支持原 String / DWord 类型；不支持的原值类型会在修改前报错，避免失真恢复。两个策略根键分别记录原来是否存在：原本存在的不删除，原本不存在的只在既无值也无子键时删除。不会递归删除注册表键；语言子键若新增了其他子键则保留并报告恢复失败。

## 先记录再修改与生命周期

恢复记录在 `%ProgramData%\YuanC\run/environment-state.json`。脚本首次读取原值后，先把 `schema=1`、`applied=false`、`original`、`target` 和 `written_at` 写入 `.tmp`，再原子替换状态文件；成功落盘才修改时区和策略。全部设置成功才更新为 `applied=true`。再次套用沿用旧记录的 `original`，只更新目标和本次执行状态，不把已经修改过的值当作最初原值。

- 连接：隧道就绪、状态为已连接之后才套用；失败不覆盖「虚拟网卡已就绪。」消息，仅更新环境状态。
- 重连：保留已套用的环境，不恢复、不重复套用；断网保护照常保持。
- 主动断开：先停隧道、撤本项目断网保护并恢复网络，然后恢复环境。即使上次套用部分失败，只要恢复记录还在，也尝试恢复；全部成功才删除记录。恢复失败不改变已断开的状态，消息为「已断开,原网络设置已恢复;但时区或浏览器设置未能恢复,请联系管理员。」。
- 服务重启：沿用已有期望状态与配对／凭据分路。满足保持保护条件时，已有环境记录视为待保持，不先恢复环境；非保持分路先恢复网络，再恢复遗留环境。启动环境恢复失败追加「启动时未能恢复上次的时区或浏览器设置,请联系管理员。」，不阻止原有自动连接流程。
- 退出界面或释放控制器不恢复环境，交给主动断开或下次启动分路。恢复中途失败保留记录，供再次断开或下次恢复重试；不要手动删除记录来掩盖失败。

## 总开关与管理员配置

界面勾选项：「连接时切换到澳洲时区与浏览器语言(环境一致性)」。默认开启；连接中关闭时立即恢复已套用设置，连接中开启时立即套用；未连接时开启只保存开关，下一次连接才套用。若套用失败留下部分修改，主动断开仍会按记录恢复。

服务配置为 `%ProgramData%\YuanC\run/environment.json`：

```json
{"enabled":true,"time_zone":"AUS Eastern Standard Time","languages":["en-AU","en"]}
```

`enabled` 是布尔开关；`time_zone` 是 Windows 时区 ID；`languages` 是按优先级排列的 1～8 个语言标识。时区 ID 只接受 1～64 个字母、数字、空格或 `.()+/-`；语言接受如 `en-AU`、`en` 的格式，不接受 `zh_CN`。文件缺失、损坏或任一字段不合法时，整份配置回到上述默认值。界面修改只更新 enabled，保留有效文件中的其他字段，以临时文件和原子替换写盘。

管理员可手改 time_zone / languages，用 `tzutil /l` 查可用 ID，并对照节点所在城市选择。建议先断开，再修改，再连接；已连接且已套用时不会因为编辑文件自动重套用。配置只由服务读取，不下放系统写入权限给界面。

五种界面状态（均加前缀「环境一致性:」）：

| 情况 | 状态文字 |
|---|---|
| 开关打开、尚未套用或恢复成功 | 未应用 |
| 开关关闭 | 未启用 |
| 套用成功 | 已切换到澳洲时区与浏览器策略 |
| 套用失败 | 设置失败,请联系管理员;连接与断网保护不受影响 |
| 恢复失败 | 恢复失败,请联系管理员 |

管道 `set_environment` 必须携带 enabled 布尔值，并通过既有调用者身份检查与指令串行队列。快照包含 `environment_enabled` 与 `environment_status`；旧快照缺字段时默认为 true 与「未应用」。只读 `InspectScript()` 只提供脚本文本，输出时区、自动时区 Start、Chrome 与 Edge 策略当前值和语言数组，本单不接入控制器或导出功能。

## 真机待验证清单

以下在 Windows 10 / Windows 11 的隔离测试机上执行，本单没有实际修改工位时区、注册表或运行真实环境脚本；自动文本检查和假件测试不能代替这些项目：

- 连接前保存时区、自动时区开关与六项策略原状；连上后 `tzutil /g` 为目标 ID，Windows 设置中「自动设置时区」为关，任务栏显示目标城市时间。
- Chrome 的 `chrome://policy` 显示 ForcedLanguages、WebRtcIPHandling、DefaultGeolocationSetting 三项；Edge 的 `edge://policy` 显示 DefinePreferredLanguages、WebRtcLocalhostIpHandling、DefaultGeolocationSetting 三项。重启 Edge 再验证 WebRTC 不报告本地接口地址。
- 访问任一回显 Accept-Language 的页面，确认首选为 en-AU；分别核对新旧浏览器配置档、同机其他账户和网站定位请求被拒绝。
- 主动断开后 `tzutil /g` 回原值，两种浏览器的三项策略消失或回到各自原值，自动时区开关回原状；原存在的语言字典精确恢复，其他策略值和子键保持。
- 连接中关闭总开关立即恢复环境，连接与断网保护继续；再次打开会套用，未连接时打开不修改环境。
- 服务重启保持连接分路中时区不回退、环境不重复套用；期望断开时先恢复网络再恢复环境。部分套用失败留下的记录也须覆盖。
- 组策略锁定时区时，界面显示「设置失败」，连接照常且断网保护不撤。模拟写记录、写策略、恢复原值失败时，核对记录保留及失败提示；恢复失败后状态仍为已断开，网络恢复不被撤回。

交付边界：源码、脚本文本、假件测试、协议与界面绑定属于本单；真实浏览器生效、系统设置恢复及服务崩溃重启表现仍待上述验证。不会将本包描述为深层指纹伪装或任何检测都无法识别的位置保证。
