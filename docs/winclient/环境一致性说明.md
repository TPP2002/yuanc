# Windows 客户端环境一致性

## 目的与承诺边界

连接到澳洲出口时，让系统时区与浏览器首选语言也与澳洲节点一致，减少网站从时区、语言、浏览器实时通信与定位接口取得不一致信息的机会。总开关默认开启，后台服务以 SYSTEM 身份执行；界面只发送指令和显示结果。

本包只承诺 IP、DNS、系统时区、浏览器首选语言四项的一致性目标，其中 IP 与 DNS 沿用既有隧道和断网保护，时区和语言按本说明设置。**不承诺任何检测都查不出**，也不把自动测试通过当作这四项的真机验收通过。环境设置失败仅告警：不改变连接状态、不停止隧道、不撤销断网保护、不自动断开；出口核验与断网保护仍按各自规则运行。

能做到：连接后设置目标时区、关闭自动时区，给 Chrome 与 Edge 设置语言、限制 WebRTC 只报告公网接口并拒绝网站定位，给 Chrome 与 Edge 打开安全 DNS 并指定与隧道同一上游；主动断开后按保存的原值恢复。连接期间任务栏时钟显示为澳洲时间，网站请求定位会被拒绝。

做不到与使用影响（承诺边界清单）：

- **不改 Windows 显示语言**，也不更改操作系统的其他区域设置。
- 不改显卡、字体、画布等深层浏览器指纹；Firefox 等其他浏览器不覆盖。
- 浏览器安全 DNS 策略只覆盖 Chrome/Edge；升级后由旧版本套用的环境要主动断开再重新连接一次，才会写入 DoH 两项。
- 策略是机器级的，对本机所有账户与所有浏览器配置档生效，并非仅当前用户或当前窗口。
- Edge 的 WebRTC 策略需重启浏览器才生效；应在连接后重启浏览器再进行相应验证。
- 不保证第三方软件、组织组策略或用户在连接期间再次修改设置后仍然一致；环境自检只报告当前证据，不自动修复环境设置。
- **跨境往返延迟**：国内到澳洲节点的网络往返约 100 毫秒以上，与澳洲本地用户的延迟特征不同；本包无法消除，也不承诺消除。
- **不改系统语言与区域信息**：不改 Windows 显示语言、区域格式（日期与数字写法）、中文语音包、中文字体清单、设备名与用户名里的中文标签。区域格式按**负责人 2026-10-22 拍板不处理：它与系统时区、浏览器语言可能不一致，属已知边界**；不增加对应自检项。
- **浏览器策略只对 Chrome 与 Edge 生效**：360、QQ、搜狗、夸克等国产浏览器与 Firefox 不在策略覆盖范围；环境自检第 5、6 项在「通过」「未通过」的明细末尾点名只覆盖 Chrome/Edge，「跳过」「无法核验」的明细保持原样。
- **一节点一使用者**：一个出口只应由一个使用者使用；多个账号或多人共用同一出口时，对方服务可能把它们关联到一起，本包不承诺隔离。
- **出口核验的证明范围**：出口核验与自检第 1、2 项只证明后台服务这一个进程的出口；名单外程序（仅指定程序模式）、其他账户不在证明范围。

销售与验收对照（下列承诺均为本说明条件下的一致性目标，不能替代真机验收）：

| 承诺 | 不承诺 |
|---|---|
| IP 一致性目标：沿用既有隧道与断网保护，按本说明核验后台服务出口与配置节点一致 | 不承诺消除跨境往返约 100 毫秒以上的延迟或达到澳洲本地用户的延迟特征；出口核验与自检第 1、2 项不证明名单外程序（仅指定程序模式）或其他账户的出口；一节点一使用者，不承诺隔离共用出口的多个账号或多人 |
| DNS 一致性目标：沿用既有隧道与断网保护，按本说明配置 DNS 经隧道 | 不承诺任何检测都查不出；配置检查不等于在线 DNS 泄漏检测，单个 IPv6 目标未连通不证明所有 IPv6 路径均被封堵 |
| 系统时区一致性目标：按本说明连接后设置目标时区、关闭自动时区，主动断开按原值恢复 | 不改 Windows 显示语言、区域格式（日期与数字写法）、中文语音包、中文字体清单、设备名与用户名里的中文标签或其他区域设置；负责人 2026-10-22 拍板区域格式不处理，与时区、浏览器语言可能不一致；不保证第三方软件、组织组策略或用户再次修改后仍然一致，自检不自动修复 |
| 浏览器首选语言一致性目标：按本说明为 Chrome 与 Edge 设置首选语言，主动断开按原值恢复 | 不覆盖 360、QQ、搜狗、夸克等国产浏览器与 Firefox；不改显卡、字体、画布等深层浏览器指纹；机器策略不隔离到当前用户或当前窗口，对本机所有账户与所有浏览器配置档生效；不承诺 Edge 的 WebRTC 策略无需重启即生效，机器策略检查不代替真实浏览器生效验证 |

## 时区切换

默认 Windows 时区 ID 是 `AUS Eastern Standard Time`。管理员按节点所在城市调整；此 ID 包括系统定义的夏令时规则，不是固定的时差。使用 `tzutil /g` 读原时区，`tzutil /s` 切换到目标时区，随后再读回核对。

自动时区来自 `HKLM:\SYSTEM\CurrentControlSet\Services\tzautoupdate` 的 `Start`：3 为按需启动（自动时区开启），4 为禁用。套用时先将 Start 设为 4，再尽力停止 `tzautoupdate`，随后切时区。恢复时先恢复原时区，再恢复原 Start；原值为 3 时尽力启动该服务。原 Start 读取不到时记录 null，不臆造原值。

读回的时区不等于目标时，状态文件写入 `verify_failed="time_zone"`，脚本退出码为 4，专用异常提示「时区切换未生效,可能被组策略锁定;连接与断网保护不受影响。」；其他命令失败同样保留原值记录。服务不把脚本标准输出或异常中的系统信息写进日志。一次执行最多 120 秒，复用既有隐藏窗口的 PowerShell 执行器，不新增进程类型。

## 浏览器十项策略

下面“十项”按浏览器策略计数：Chrome 的语言是一整个 `ForcedLanguages` 子键，另外九项是根键上的单值。不另外创建同名根值，不写 `ApplicationLocaleValue`，也不修改其他策略。

| 浏览器 | 注册表路径 | 值名 | 类型 | 写入值 | 原值记录 | 恢复方式 |
|---|---|---|---|---|---|---|
| Chrome | `HKLM:\SOFTWARE\Policies\Google\Chrome\ForcedLanguages` | `1`、`2`… | REG_SZ | 按序号 `en-AU`、`en`，或配置数组 | 子键是否存在及全部名称→值字典 | 原存在则清空当前值、逐个写回；原不存在则仅删除此子键 |
| Chrome | `HKLM:\SOFTWARE\Policies\Google\Chrome` | `WebRtcIPHandling` | REG_SZ | `default_public_interface_only` | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Chrome | 同上 | `DefaultGeolocationSetting` | REG_DWORD | `2`（拒绝定位） | 是否存在、原类型、原值 | 同上 |
| Chrome | 同上 | `DnsOverHttpsMode` | REG_SZ | `secure` | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Chrome | 同上 | `DnsOverHttpsTemplates` | REG_SZ | `https://1.1.1.1/dns-query` | 是否存在、原类型、原值 | 同上 |
| Edge | `HKLM:\SOFTWARE\Policies\Microsoft\Edge` | `DefinePreferredLanguages` | REG_SZ | `en-AU,en`，或配置数组以逗号连接 | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Edge | 同上 | `WebRtcLocalhostIpHandling` | REG_SZ | `default_public_interface_only` | 是否存在、原类型、原值 | 同上；需重启浏览器生效 |
| Edge | 同上 | `DefaultGeolocationSetting` | REG_DWORD | `2`（拒绝定位） | 是否存在、原类型、原值 | 同上 |
| Edge | 同上 | `DnsOverHttpsMode` | REG_SZ | `secure` | 是否存在、原类型、原值 | 原存在按原类型写回，否则仅删除此值 |
| Edge | 同上 | `DnsOverHttpsTemplates` | REG_SZ | `https://1.1.1.1/dns-query` | 是否存在、原类型、原值 | 同上 |

安全 DNS 选择 `https://1.1.1.1/dns-query`，因为它与 sing-box 的 `dns-remote` 上游相同。全部流量模式下浏览器经隧道解析；仅指定程序模式下，名单外浏览器直连 1.1.1.1，不再把域名交给国内 DoH。这不表示名单外浏览器的解析出口也在澳洲。

套用语言前先保存 `ForcedLanguages` 的所有值，再逐个移除当前值并按 1 起的序号写入目标语言。单值恢复支持原 String / DWord 类型；不支持的原值类型会在修改前报错，避免失真恢复。两个策略根键分别记录原来是否存在：原本存在的不删除，原本不存在的只在既无值也无子键时删除。不会递归删除注册表键；语言子键若新增了其他子键则保留并报告恢复失败。

## 先记录再修改与生命周期

恢复记录在 `%ProgramData%\YuanC\run/environment-state.json`。脚本首次读取原值后，先把 `schema=1`、`applied=false`、`original`、`target` 和 `written_at` 写入 `.tmp`，再原子替换状态文件；成功落盘才修改时区和策略。全部设置成功才更新为 `applied=true`。再次套用沿用旧记录的 `original`，只更新目标和本次执行状态，不把已经修改过的值当作最初原值。

- 连接：隧道就绪、状态为已连接之后才套用；失败不覆盖「虚拟网卡已就绪。」消息，仅更新环境状态。
- 重连：保留已套用的环境，不恢复、不重复套用；断网保护照常保持。
- 主动断开：先停隧道、撤本项目断网保护并恢复网络，然后恢复环境。即使上次套用部分失败，只要恢复记录还在，也按六步尽力而为：时区（time_zone）、自动时区（tzautoupdate）、Chrome（chrome）、Edge（edge）、语言子键（forced_languages）、空策略根键清理（cleanup）。任一步失败不拦住其余步骤，全部跑完后把失败步骤写进 `restore_failed` 并保留记录，界面仍显示「恢复失败,请联系管理员」；全部成功才删除记录。下次断开或启动进入恢复分路时，按同一记录重试全部六步，已恢复步骤可幂等重做。旧版本记录没有 DoH 两项值名时跳过，不算失败。恢复失败不改变已断开的状态，消息为「已断开,原网络设置已恢复;但时区或浏览器设置未能恢复,请联系管理员。」。
- 服务重启：沿用已有期望状态与配对／凭据分路。满足保持保护条件时，已有环境记录视为待保持，不先恢复环境；非保持分路先恢复网络，再恢复遗留环境。启动环境恢复失败追加「启动时未能恢复上次的时区或浏览器设置,请联系管理员。」，不阻止原有自动连接流程。
- 退出界面或释放控制器不恢复环境，交给主动断开或下次启动分路。恢复中途失败保留记录，供再次断开或下次恢复重试；不要手动删除记录来掩盖失败。

## 总开关与管理员配置

界面勾选项：「连接时切换到澳洲时区与浏览器语言(环境一致性)」。默认开启；连接中关闭时立即恢复已套用设置，连接中开启时立即套用；未连接时开启只保存开关，下一次连接才套用。若套用失败留下部分修改，主动断开仍会按记录恢复。

服务配置为 `%ProgramData%\YuanC\run/environment.json`：

```json
{"enabled":true,"time_zone":"AUS Eastern Standard Time","languages":["en-AU","en"],"country":"AU"}
```

`enabled` 是布尔开关；`time_zone` 是 Windows 时区 ID；`languages` 是按优先级排列的 1～8 个语言标识。时区 ID 只接受 1～64 个字母、数字、空格或 `.()+/-`；语言接受如 `en-AU`、`en` 的格式，不接受 `zh_CN`。文件缺失、损坏或上述三个字段不合法时，整份配置回到上述默认值。`country` 是自检期望国家码，仅接受两个大写字母（`^[A-Z]{2}$`），缺失或不合法时仅国家码回到 `AU`，保留其他有效设置。界面修改只更新 enabled，保留有效文件中的其他字段，以临时文件和原子替换写盘。

管理员可手改 time_zone / languages，用 `tzutil /l` 查可用 ID，并对照节点所在城市选择。建议先断开，再修改，再连接；已连接且已套用时不会因为编辑文件自动重套用。配置只由服务读取，不下放系统写入权限给界面。

**时区与国家码随节点下发**：自用版从配对文件的 `node.time_zone`、`node.country` 读取，分发版从鉴权会话的同名字段读取。每个字段的优先级是**节点下发 > 本机 environment.json > 默认值**；未下发时沿用本机配置，再没有有效本机配置时使用默认时区 `AUS Eastern Standard Time` 与国家码 `AU`。旧配对文件、旧鉴权服务器无需修改；会话里的空串表示未下发，配对文件未设置时应省略键。

节点的 `time_zone` 接受 IANA 名（如 `Australia/Perth`）与 Windows 时区 ID（如 `W. Australia Standard Time`），先尝试把 IANA 名转换为 Windows ID，再检查是否是系统可识别的时区标识。无法识别，或解析结果不满足既有目标格式限制时，时区回落本机配置，不影响 `country` 的采用；`country` 为两位大写国家码，供出口国家自检使用。`languages` 仍只由本机配置决定，不随节点下发。

会话续期改变了实际生效时区时，先恢复原环境再重新套用，不重启隧道；只改变国家码不触发环境重套用。恢复或套用失败只更新环境状态，保留连接与断网保护，不覆盖连接消息。按「待拍板 d」已选暂不签名的口径，配对文件未签名，这两个字段同样可被篡改：只影响系统时区与自检期望国家，不改变实际出口，不能据此证明节点地理位置可信。

五种界面状态（均加前缀「环境一致性:」）：

| 情况 | 状态文字 |
|---|---|
| 开关打开、尚未套用或恢复成功 | 未应用 |
| 开关关闭 | 未启用 |
| 套用成功 | 已切换到澳洲时区与浏览器策略 |
| 套用失败 | 设置失败,请联系管理员;连接与断网保护不受影响 |
| 恢复失败 | 恢复失败,请联系管理员 |

管道 `set_environment` 必须携带 enabled 布尔值，并通过既有调用者身份检查与指令串行队列。快照包含 `environment_enabled` 与 `environment_status`；旧快照缺字段时默认为 true 与「未应用」。只读 `InspectScript()` 输出时区、自动时区 Start、Chrome 与 Edge 策略当前值和语言数组，由后台自检读取。

## 环境自检

每次出口核验到达「已核验」「不一致」或五次无结果后的「无法核验」终局，后台服务在同一串行回调中执行八项自检，完成后再安排五分钟出口复查。开启环境一致性时运行只读巡查，最多等待 60 秒；关闭时不运行巡查。IPv6 探测每轮只向固定字面地址 `[2606:4700:4700::1111]:443` 发起一次 TCP 连接，最多等待 3 秒，不查询域名、不重试其他目标。

| 编号（报告标识） | 名称 | 判定 |
|---|---|---|
| 1（exit_country） | 出口归属澳洲 | 探测点国家码等于配置 country（默认 AU）通过；不同未通过；无出口或国家码则无法核验 |
| 2（exit_node） | 出口与节点一致 | 出口地址与当前会话节点地址相同通过，不同未通过；无出口则无法核验 |
| 3（time_zone） | 系统时区 | 当前 Windows 时区 ID 与目标 ID 相同通过，否则未通过；巡查失败无法核验，关闭总开关跳过 |
| 4（auto_time_zone） | 自动时区已关 | 自动时区服务 Start 为 4 通过，其他值未通过；值缺失或巡查失败无法核验，关闭总开关跳过 |
| 5（chrome_policy） | Chrome 策略 | ForcedLanguages 顺序与目标语言完全一致，WebRtcIPHandling 为 default_public_interface_only，DefaultGeolocationSetting 为 2，DnsOverHttpsMode 为 secure，DnsOverHttpsTemplates 为 https://1.1.1.1/dns-query，五项全符合通过；否则未通过；巡查失败无法核验，关闭总开关跳过。明细末尾注明只覆盖 Chrome/Edge |
| 6（edge_policy） | Edge 策略 | DefinePreferredLanguages 等于目标语言逗号拼接，WebRtcLocalhostIpHandling 为 default_public_interface_only，DefaultGeolocationSetting 为 2，DnsOverHttpsMode 为 secure，DnsOverHttpsTemplates 为 https://1.1.1.1/dns-query，五项全符合通过；否则未通过；巡查失败无法核验，关闭总开关跳过。明细末尾注明只覆盖 Chrome/Edge |
| 7（no_direct_path） | 配置无直连路径 | 全部流量：route.final 为 proxy、route.rules 存在 IPv6 到 block 的规则、dns.servers 每项 detour 为 proxy、outbounds 无 direct 类型，四条全满足通过；缺键或不符未通过。仅指定程序：final 为 direct、proxy 规则覆盖全部指定程序路径正则、IPv6 block 规则覆盖同一名单、DNS 每项 detour 为 proxy；明细以「仅指定程序模式:」开头 |
| 8（ipv6_direct） | IPv6 已封堵 | 全部流量：固定目标连接成功则未通过，显示「IPv6 可直连,可能泄漏」；超时、异常或本机无 IPv6 导致未连上则通过；没有探测结果则无法核验。仅指定程序：不发整机 IPv6 探测，结果「跳过」，明细「仅指定程序模式不检测整机 IPv6;指定程序的 IPv6 已由配置与防火墙阻断」 |

四种结果含义：

仅指定程序模式的跳过项同样计入「未能检查」；其他七项均通过时汇总为「7 项通过,1 项未能检查」。第七项读取渲染后的配置，名称沿用，但不表示名单外程序没有直连。出口国家和节点核验来自后台服务，仅证明该进程；系统 DNS 经隧道，名单外浏览器的安全 DNS 则直连 1.1.1.1；系统时区及 Chrome / Edge 机器策略仍整机套用，名单外直连浏览器可能报告澳洲时区和 en-AU，银行支付网站可能判异常。完整局限见 [分应用代理说明](分应用代理说明.md)。

| 结果 | 含义 |
|---|---|
| 通过 | 本次输入满足该项判定条件，不表示已证明所有网络路径安全 |
| 未通过 | 本次输入存在明确不符项；浏览器只列不符值名，配置只列缺失条件 |
| 跳过 | 环境一致性总开关关闭时四项系统与浏览器检查未执行；仅指定程序模式下第八项整机 IPv6 检查也跳过 |
| 无法核验 | 缺少探测结果、国家码、巡查数据或必要读数；不当作通过 |

界面在断网保护巡检行后显示「环境自检:未检测」，运行中显示「环境自检:检测中」。全好时显示「环境自检:8 项通过」；没有失败但有未检查项时显示例如「环境自检:4 项通过,4 项未能检查」；有失败时显示「环境自检:1 项未通过:系统时区」，多项名称以「、」连接。离开已连接状态清回「未检测」，关闭总开关后的检查汇总在下一轮更新。

完整报告保存到 `%ProgramData%\YuanC\run/selfcheck.json`，通过 `.tmp` 写入、刷盘并原子替换，包含 `checked_at`、`summary`、`items`（每项 `id/name/result/detail`）。报告只含判定证据、国家码或时区 ID，不写出口 IP，不记录探测响应正文；写入失败不影响连接及界面检查结果。文件保留最近成功落盘的一轮，判断时应看 checked_at。

「导出诊断」依次读取 `read_audit` 与只读指令 `read_selfcheck`，保存为 `诊断报告.json`：`{"firewall_audit": <审计对象或 null>, "self_check": <自检对象或 null>}`。两段均以 JSON 原样嵌入，不变成字符串；两者都不存在时提示「尚无可导出的诊断记录,请完成一次连接后重试。」；成功提示「已导出诊断(防火墙审计 + 环境自检)。」。报告读取经过服务指令队列，不受调用者修改权限核验限制，超出管道长度上限返回错误而不截断。

**自检只报告，不修复、不断开、不撤保护、不改任何系统设置，也不覆盖连接消息。自检通过不等于任何检测都查不出。** 国家归属只采信出口探测点返回的国家码这一个数据源，不证明家庭宽带属性。配置检查不等于在线 DNS 泄漏检测；单个 IPv6 目标未连通也不能证明所有 IPv6 路径均被封堵。检查读取的是机器策略，不代替真实浏览器生效验证。
