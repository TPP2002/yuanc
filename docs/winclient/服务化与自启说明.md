# Windows 客户端服务化与自启

## 角色、权限与安装位置

同一个单文件程序由自定义 `[STAThread] Main` 按第一个参数选择角色，界面清单为 `asInvoker`：

| 参数 | 行为 |
|---|---|
| 无参数 | 普通用户界面，立即显示窗口 |
| `--tray` | 普通用户界面，只显示托盘 |
| `--service` | 后台服务宿主，不创建 WPF Application |
| `--install` | 管理员安装动作，失败返回 1 |
| `--repair` | 管理员动作，核验并修正数据目录权限，启动未运行的后台服务 |
| `--uninstall` | 管理员卸载动作 |
| `--apply-update` | 旧后台启动的更新助手，不创建界面 |
| 未知参数 | 向标准错误输出中文说明并返回 2 |

后台服务名 `YuanCService`，显示名「YuanC 澳洲出口连接服务」，以 LocalSystem 运行，依赖 BFE，开机自动启动。服务失败后由系统依次间隔 5、10、30 秒重启，失败计数重置周期为 86400 秒，并启用非崩溃失败动作。无需额外看门狗。

安装程序只复制当前单文件 exe 到 `%ProgramFiles%\YuanC\app\<Version>\YuanC-Client.exe`。Version 取程序集 InformationalVersion 去掉 `+` 后缀，默认与 Directory.Build.props 一致。相同 SHA256 跳过复制；服务配置及注册表同值重复安装不改变最终状态。任一步失败返回 1 并输出中文原因，不回滚已成功步骤，可以重新运行。此目录布局也用于自用模式自动更新：后台验签和暂存，旧版启动 `--apply-update` 助手完成服务切换、健康检查与回退，见 [自动更新说明](自动更新说明.md)。

登录自启写入 `HKLM\Software\Microsoft\Windows\CurrentVersion\Run` 的 `YuanC` 值，内容是带引号的目标 exe 绝对路径及 `--tray`。服务自启不依赖用户登录；用户登录后才启动托盘界面。

客户双击后点击「安装后台服务(需管理员确认一次)」，界面用 `runas` 拉起自身的安装角色。首次安装只需一次 UAC；以后正常启动界面不弹 UAC。显式修复或卸载仍是管理员动作。所有系统命令用绝对路径、参数列表、隐藏窗口执行；唯一的 ShellExecute 例外是上述提权入口。

## 后台与界面分离

仅后台服务创建 ClientRuntime，持有内核、断网保护、凭据及配对存储。后台日志经 RedactingLog 写入滚动的 `%ProgramData%\YuanC\run\service.log`，不记录异常原文、邀请码或配对正文。后台未处理异常以非零状态退出，交给系统失败动作重新启动。

包使用缓存中的 `System.ServiceProcess.ServiceController 10.0.9`。按派单方第一次答复，允许其自动引入 `System.Diagnostics.EventLog 10.0.9` 间接依赖；App/Core 均不直接引用该包、不调用该接口。服务 `AutoLog=false`，不写 Windows 事件日志。

窗口关闭只隐藏到托盘；托盘提供「打开窗口 / 连接 / 断开 / 退出界面(隧道不受影响)」。退出界面、界面异常和界面崩溃均不操作内核或防火墙。第二个界面实例通过 `Local\YuanC-ShowWindow` 命名事件唤起第一个窗口并退出。

服务停止或系统关机时关闭管道、释放运行时，停内核但不主动撤销断网保护。显式断开（包括卸载前发出的断开）走原有撤防流程。再次启动按下文期望状态分路，满足保持条件时不撤防；状态机迁移表及重试退避不变。

服务未安装时提示安装；已安装未运行时提示修复。服务运行但无法连接管道时，每次连接超时 3 秒，初次失败后重试 5 次，间隔 1 秒，最终提示「无法连接后台服务,请重启电脑或联系管理员」。

## 本机管道协议

入口为 `\\.\pipe\YuanC-Control`，最多 4 个并发实例，每个连接独立读循环。权限关闭继承：SYSTEM、BUILTIN\Administrators 为 FullControl，BUILTIN\Users 为 ReadWrite，Network SID 明确拒绝 FullControl；不监听 TCP。真实本机与网络身份访问效果仍须真机验收。

Core 的 ControlServer/ControlClient 只接收 Stream。App 负责创建命名管道。每条消息为 UTF-8 JSON 对象加 `\n`，单行最多 1 MiB（不计终止换行），超限只断开对应连接，未以换行结束的残帧不执行。

请求：`{"id":1,"op":"status"}`。id 为客户端自增整数；op 支持 `status`、`connect`、`disconnect`、`redeem`、`import_pairing`、`clear_pairing`、`read_audit`、`subscribe`、`check_update`。检查更新立即返回当前进度；快照增加 `service_version` 和 `update`，更新状态变化也推送。兑换附 `code`，导入附 `pairing_json`，均为字符串。

应答含同请求 `id`、`ok`，可附 `error`、`snapshot`、`audit`。快照字段为 `state`（既有状态枚举名称）、`status`、`message`、`protection_active`、`mode`。订阅后每次状态变化推送 `{"event":"snapshot","snapshot":{...}}`。未知 op 返回 `ok=false,error="不支持的指令"`；坏 JSON 返回 `id=null,ok=false,error="指令格式错误"`，两者均保持连接。错误不转发异常原文。

`ok` 表示指令处理结果，连接是否建立以快照状态为准。导入在界面读取用户选定文件后传正文，服务校验和保存；导出由服务返回审计全文或 null，界面写入用户选择的位置。若审计全文编码后超过协议单行上限，返回中文错误，不截断审计文件。

## 安全存储与期望状态

安装复制程序之后、配置服务之前，以及修复启动服务之前，核验 `%ProgramData%\YuanC` 根目录和 `run`、`secure`、`updates` 子目录。后台服务每次启动也先核验这些目录，再执行更新恢复和创建运行时。加固时全部断开 ACL 继承，删除原有权限，只保留 SYSTEM 与 BUILTIN\Administrators 两条可由文件和子目录继承的完全控制权限，所有者设为 Administrators；普通用户无任何访问权限。已有 `bin` 目录同样核验，不存在时不主动创建。

核验拒绝目录联接、符号链接等重解析点，所有者必须是 SYSTEM 或 Administrators，不允许其他身份的 Allow 权限，也不允许针对这两类身份的 Deny 权限。不合格目录能修就修，修正一次后重新核验；重解析点或无法修正的目录导致拒绝启动。安装失败提示「数据目录权限设置失败，请以管理员身份重试或联系管理员。」并返回 1；服务写入 `run/service.log`「数据目录权限异常，后台服务拒绝启动：<异常文案>」，随后按既有致命退出流程交由系统失败动作处理。异常文案仅含目录相对名和固定中文原因；即使日志无法写入也必须非零退出。

普通用户不需要读取该数据目录：界面只经本机命名管道与服务通信，导入由界面传入用户选定的文件正文，导出审计由服务经管道返回后写入用户选定位置。后台的刷新凭据、配对文件、设备标识分别存为 `secure/credential.bin`、`secure/pairing.bin`、`secure/device-id`，使用 LocalMachine DPAPI；机器范围加密必须结合目录权限，不能单靠 DPAPI 隔离本机用户。

读取 `server.json` 前核验文件所有者须为 SYSTEM 或 Administrators；`server_url` 必须使用 IPv4 数字地址的 HTTPS 地址，不使用域名或 IPv6。配置中的 `sing_box_path` 必须是 `%ProgramFiles%\YuanC` 安装目录下的绝对路径，禁止 `..` 路径段。未提供该字段时仍使用内嵌内核。观察项：本次不处理安装前已放入 `run`、`secure` 等目录的旧文件内容，也不删除或重加密密文，历史内容的可信性仍需另行评估。

不做 `%LOCALAPPDATA%`、CurrentUser DPAPI 旧数据迁移：产品尚未交付客户。Core 旧调用默认保持原有用户目录及存储行为；仅服务明确传 secure 根目录和 LocalMachine scope。原有默认设备标识文本格式保留，服务使用加密格式。明文运行配置和防火墙审计所在的 `run` 目录纳入同等加固；期望状态的写入方式不变，启动按下述规则分路。

`%ProgramData%\YuanC\run\desired.json` 示例：`{"connect":false,"updated_at":"2026-10-22T00:00:00.0000000+00:00"}`。通过 `.tmp` 写入、刷盘后原子覆盖。显式连接处理后写 true，显式断开处理后写 false。启动先完成数据目录核验与更新恢复，再读取期望状态，之后才创建运行时。期望不是 false 且有恢复记录、有配对或鉴权凭据时，保持保护直接重连，不先恢复网络；false 时恢复网络并发布状态，不自动连接。文件缺失或解析失败返回 null，按不是 false 处理。没有配对／凭据或服务器配置时走既有恢复路径；没有恢复记录时恢复入口不操作防火墙，再按既有条件自动连接。关闭窗口、退出界面、停止服务不会修改期望状态。

保持保护启动后，分发版直接重新鉴权，自用版使用配对会话；成功后重新套用规则，再启动隧道。鉴权网络错误按既有退避重试，界面先显示重连中，耗尽转需人工处理，保护全程保持。用户可点「连接」重试，要恢复普通网络必须点断开。分发版的 `YuanC-KS-Auth` 仅放行服务进程到配置的鉴权服务器 IPv4:端口，只允许 TCP；自用模式不加这条规则，不放行系统 DNS。两层降级恢复只用于恢复路径，详见 [服务重启时保持保护](断网保护加固说明.md#服务重启时保持保护)。

## 卸载

由管理员运行已安装程序的 `--uninstall`。先连接管道发送 disconnect；连接不上则输出中文说明并跳过该步，可能残留的断网保护需管理员处理。连接成功但撤防失败时明确报错，不假装卸载成功。随后停止服务（最多等待 30 秒）、删除服务、删除登录自启值。重复卸载能处理服务或自启值已不存在的情况。

保留 `%ProgramData%\YuanC`，其中包含凭据、配对文件、日志、期望状态和恢复记录；如需手动清理，先由管理员确认服务已卸载、网络已恢复，再删除该产品目录。程序版本目录也不自动清理。

## 真机待验证清单

以下尚未执行，不能用编译、单测或单文件发布通过代替：

- 连接中结束后台进程，服务被系统拉起期间另开程序持续 ping 公网，应全程无回应，直到隧道重新就绪。
- 把鉴权地址改成不可达的 IPv4 数字地址后重启服务，期间另开程序持续 ping 公网，应全程无回应，直到用户点断开；界面先显示重连中，重试耗尽后显示需人工处理。
- 期望为断开时重启服务，应恢复网络、不自动连接。
- 干净 Windows 10/11：普通用户双击不提权，首次安装只弹一次 UAC；取消提权可重试。
- 首装、重复安装、失败后重跑、修复、卸载；路径含空格，安装哈希及注册表同值不重复改写。
- 服务以 LocalSystem 依赖 BFE 开机启动；无用户登录也能按期望状态连接；断开后重启不自动连。
- 强制终止后台进程，核对系统失败动作及脱敏 service.log；停止服务保留保护，主动断开恢复网络。
- 登录托盘自启、首次双击显示窗口、关窗口隐藏、托盘四项操作、第二实例唤起、退出界面不掉隧道。
- 普通用户可用管道但不可读 secure；SYSTEM/管理员可管理；远程网络身份被拒；四客户端并发及第五连接等待。
- 普通用户对 `%ProgramData%\YuanC` 及子目录执行 Get-Acl，确认无法访问、看不到 Users 项；管理员复核权限断继承且只有 SYSTEM 与 Administrators，并用 Get-Acl 核对所有者为 Administrators、icacls 核对权限（icacls 的常规显示不包含所有者）。
- 普通用户预先建好带 Users 写权限的数据目录后安装，确认安装后所有者和权限被修正；旧文件内容保留，列为观察项。
- 停止服务后把 `run` 换成目录联接，再启动服务，确认拒绝启动且日志包含「数据目录权限异常」；记录系统重启尝试和最终服务状态，不以单测代替。
- 界面崩溃时连接保持；真实 TUN、DNS/IPv6、网络出口与断网保护按既有边界验证。
- 未签名单文件的 SmartScreen、Defender 提示及发布包中的托盘、服务组件加载。
